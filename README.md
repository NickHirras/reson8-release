# Reson8 — Linux downloads

Flatpak bundles for [Reson8](https://reson8tuner.com), the precision instrument tuner.

## Install

Download the latest `.flatpak` bundle from the table below, then:

```
flatpak install --user ./reson8-<version>.flatpak
```

(Requires the GNOME 47 runtime; flatpak will fetch it from Flathub automatically.)

Prefer the Snap Store? `snap install reson8`.
