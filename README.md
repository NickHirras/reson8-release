# Reson8 releases

Linux builds of [Reson8](https://reson8tuner.com/), published by the
release workflows in the main repository and served from this
repository's GitHub Pages site. How to install each format, and how
the deb and rpm keep themselves updated, is on the website:
<https://reson8tuner.com/download/linux/>.

The newest build of every format is always at `latest/`; the table
below is the versioned archive. Older versions are pruned from this
tree (they remain in git history).
